哈喽大家好，我是欧呦，这篇文章将为大家分享个人开发者如何接入收款。

现在借助 AI Agent 和 Vibe Coding，一个个人开发者把自己的网站、小工具或者 Skill 产品做出来已经非常快了。但是当你想把做出来的产品加上付费功能、真正跑通商业化的时候，往往马上就会卡在「怎么收钱」这件事上：

- 去申请微信支付或支付宝的常规官方接口，发现必须要求有企业营业执照，个人身份根本开不了；
- 想同时接国内用户和海外用户的钱，不知道选什么平台既能支持微信和支付宝付款，又能直接收海外用户的美金；
- 哪怕听说了 [Stripe](https://stripe.com/) 个人可以开通，但在实际准备香港银行卡、填写香港地址与身份信息、以及把支付和回调代码接进网站时，还是不清楚具体每一步该怎么操作。

这篇我就结合自己的实际经验，把为什么选择 [Stripe](https://stripe.com/) 、个人怎么去香港办卡并开通香港 Stripe、以及怎么用 AI Agent 快速把支付功能接进网站完整梳理一遍。

## 为什么个人收款选 Stripe

作为一个没有公司主体的国内个人开发者，如果想要直接去申请微信支付或支付宝的常规官方商户接口，都是需要企业资质（营业执照）的，个人没法直接开通。

当然，国内也有一些支持个人开发者接入的收款渠道：

- **[虎皮椒](https://www.xunhupay.com/)** ：面向个人开发者的微信、支付宝聚合支付接口服务商，支持个人实名签约。
- **[链动小铺](https://www.ldxp.cn/)** ：面向个人开发者与数字商品的自动发卡和代收结算平台。
- **[支付宝 AI 付](https://open.alipay.com/)** ：支付宝现在推出的针对 AI 应用与智能体的支付方案，也是支持个人开发者接入的。

那为什么我没有用国内这些个人渠道，而是直接选择了 [Stripe](https://stripe.com/) ？主要有以下两个原因：

### 1\. 既能兼顾国内用户，也能同时做出海

作为个人开发者，如果你只去接了国内的支付渠道，那么基本上你就告别海外用户了。

而如果你用 [Stripe](https://stripe.com/) ，你既可以在里面开通支付宝和微信支付来兼顾国内用户，也可以同时做出海收美金。因为你的项目早期在国内社媒分享时肯定会有曝光，需要方便国内用户付款；但是到了后期，你完全可以通过 SEO（搜索引擎优化）的方式吸引到海外的流量，再给网站做一下国际化，这些都是一些低成本的收入。

![国内个人收款渠道与香港 Stripe 个人账户的对比](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/01-domestic-vs-stripe-payment-v1.svg)

国内个人收款渠道与香港 Stripe 个人账户的对比

### 2\. 目前最主流的收款平台，没有额外的维护负担

至于海外其他的收款平台，我没有去试过。因为 [Stripe](https://stripe.com/) 就是目前最主流的收款平台，我不想有其他的维护性质负担；而且我在平时工作的时候，我们自己团队的 SaaS 产品就是用的 Stripe，所以我下意识地就去注册了这一个。

同时，Stripe 没有月租费，在没有交易量之前是不扣任何费用的，只有在成功收款时才会按笔扣除手续费（例如香港账户基础费率约为 `3.4% + HK$2.35/笔` ，微信/支付宝约为 `2.2% + HK$2/笔` ，跨币种结算另加约 `2%` 货币转换费）。

这里有一点需要注意：因为每笔交易除了百分比抽成之外，还有一笔固定起步费用和跨币种转换费，所以 **产品定价不能太低** 。不要去搞那种一两美元的定价（否则手续费占比会很高），至少要定在 `5 美元` 、 `10 美元` 这种区间才比较合适。

## 香港 Stripe 准备与注册

### 1\. 需要提前准备什么？

国内个人开发者想要注册开通香港地区的 [Stripe](https://stripe.com/) 个人账户，需要提前准备好以下几样东西：

1. **身份证** 与 **护照** （去香港过关还需准备好 **港澳通行证** ）。
2. **香港的过境证明（出入境记录）** ：过关进入香港后，在微信搜索「移民局 12367」小程序即可导出出入境记录凭证，线上办理港卡时需要上传，且必须在香港境内才能开通。
3. **一张香港银行卡** ：我们需要先有一张港卡用来收款结算。我办的是 **众安银行（ [ZA Bank](https://bank.za.group/) ）** ，另外香港还有 **汇丰银行（ [HSBC HK](https://www.hsbc.com.hk/) ）** 这些。只要去到香港就可以线上办理，下载它们的手机软件就好了，但是必须要求人在香港境内。
4. **先把产品网站上线好** ：在去申请开通 Stripe 和对应支付方式之前，我是先把自己的产品网站上线好的。
![个人开通香港 Stripe 的前置准备：护照、12367 出入境记录、香港银行卡与产品官网](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/03a-hk-stripe-prep-items-v1.svg)

个人开通香港 Stripe 的前置准备：护照、12367 出入境记录、香港银行卡与产品官网

### 2\. 注册和激活时怎么填写？

准备好港卡和网站之后，去 [Stripe](https://stripe.com/) 注册选择 **香港（HK）个人账户** 即可。在填写激活信息时，有两个大家经常会问到的地方：

- **身份证件怎么填** ：表单里面需要填香港身份证的地方，我直接把我的 **护照号码** 填上去就好了，就顺利开通了。
- **香港地址怎么填** ：注册和激活的过程中有一个填地址的步骤，我填的是一个香港的虚拟/办公地址——具体填的是香港数码港的地址（也就是众安银行办公大楼所在的地址：区域选 `香港島 - Hong Kong` ，地址填 `Core F, Cyberport 3, 100 Cyberport Road` ）。

这种方式在个人项目早期和小体量阶段完全够用；如果后续你的业务流水做得比较大，触发了平台的二次地址账单核验或身份复核，到那时再考虑注册一个香港公司主体来升级账户即可。

![香港 Stripe 个人账户注册与激活填写：在港办妥众安港卡，填写护照号与香港数码港地址](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/03b-hk-stripe-registration-v1.svg)

香港 Stripe 个人账户注册与激活填写：在港办妥众安港卡，填写护照号与香港数码港地址

### 3\. 开启支付宝与微信支付，以及禁售红线与资金使用

账号激活之后，在 Stripe 后台申请开通「支付宝（Alipay）」和「微信支付（WeChat Pay）」一般来说都很顺利，我基本上每一个产品都可以正常开通支付宝和微信支付。这里有两个容易踩坑的地方要特别提醒一下：

- **只支持一次性买断** ：在 Stripe 里面如果要支持微信或者支付宝支付，只支持 **一次性买断（单次付款）** ，是没有办法走订阅制自动扣款的。
- **注意合规与禁售业务红线** ：微信支付和支付宝的跨境通道对业务类目审查比较严格。正常的独立软件、AI 工具、Skill 产品都很容易通过；但像 VPN/代理服务、API 聚合转发中转、共享账号合租等擦边或灰产业务属于平台明令禁止的红线，一旦涉及很容易被拒批甚至封号冻结资金。

至于收上来的钱打到我的香港银行卡（众安银行）上之后，我一般都不直接提回国内，平时直接拿这张卡用来消费——比如购买一些海外的软件服务、AI 订阅产品就好了。

![香港 Stripe 开通支付宝与微信支付：仅支持单次买断、避开禁售红线并用港卡直接消费](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/03c-hk-stripe-alipay-wechat-v1.svg)

## 用 AI 与官方插件接入代码

### 1\. 用 AI Agent 的 Stripe 官方插件直接写代码

很多人会担心接支付接口的代码很难写，其实这一部分代码现在非常简单。

现在很多主流 AI Agent 里面都有 **[Stripe 的官方插件](https://docs.stripe.com/agents)** 。你使用 Stripe 的官方插件连接成功、授权成功之后，它里面已经内置了很多 Stripe 的最佳实践——包括怎么样去创建产品、怎么样在你本地调用它们的 SDK 和库、怎么样快速去支持支付功能、点击购买之后跳转到结账门户、门户里面怎么样去配置，以及如何去实现退款。

至于「怎么把付款跟网站里的用户账号关联起来」以及「怎么检查支付状态」：因为我们的网站一般都是要求用户先登录（鉴权）之后才能去支付，不会不鉴权就让用户直接付款，所以支付订单跟后端数据库里面的用户表天然就是有关联的。现在很多 AI 都非常了解这一点，包括支付后的状态核对与检查，直接让 AI 来写和检查，它默认都会处理得很清楚。

这些现在不用很懂底层技术都可以跑通，任何一个主流 Agent 都能做到。

![用 AI Agent 的 Stripe 官方插件直接编写支付、结账门户与用户订单关联代码](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/02a-stripe-agent-plugin-v1.svg)

### 2\. 你真正需要大致了解的几个核心概念

虽然代码可以让 AI Agent 帮你写，但你只需要大致了解 Stripe 里面下面这几个核心概念是什么就好了：

1. **沙盒（Sandbox）与正式环境** ：沙盒是 Stripe 提供的隔离测试环境。在开发阶段，你可以在沙盒里面创建测试商品、模拟付款流程，验证代码逻辑是否正常，不会产生真实的资金扣款；全部调通之后，再切换到正式环境（Live Mode）。
2. **产品（Product）与价格（Price）** ：你需要清楚在 Stripe 里面每个产品的概念是什么、价格怎么配。
	- **关于币种与风控设置** ：面对不同地区的用户， **海外用户我就定美金（ `USD` ），国内用户我就定人民币（ `CNY` ）** （在同一个 Product 下面可以分别配置不同币种的 Price）。另外，面向海外用户用信用卡收美金时，为了防止黑产拿盗刷卡恶意测试导致拒付（Dispute）产生额外罚金，记得在后台保持开启 Stripe 默认的 Radar 风控与 3DS 验证，遇到可疑订单主动原路退款。
		- **关于多产品与账号管理** ：我自己的 `oiloil` 系列产品（比如 [ui.oiloil.org](https://ui.oiloil.org/) 、 [book.oiloil.org](https://book.oiloil.org/) 等）都是放在同一个香港 Stripe 账户底下，通过创建不同的 Product 来区分管理的；另外我也有其他的 Stripe 账号，用来放非 `oiloil` 系列的产品。
3. **结账门户（Checkout）与客户门户（Customer Portal）** ：用户在你的网站上点击购买后，会直接跳转到 Stripe 托管的结账门户页面完成扫码（支付宝/微信）或银行卡支付；而客户门户则是供用户查看自己的历史账单或管理购买记录的托管页面。
4. **Webhook 回调** ：当用户在结账门户完成付款后，Stripe 的服务器会主动向你的网站后端发送一条 Webhook 回调通知，告诉你的后端这笔订单已经支付成功，从而触发数据库更新并发放对应的产品权益或授权码。

## 沙盒测试与正式上线收款

当我们在沙盒环境里把流程跑通、切换到正式环境上线收款时，怎么确认线上真的没问题了？

![正式环境上线收款的真机验收闭环：Agent 自动操作前序结账、手机真机扫码付款与 Webhook 日志核验](https://book.oiloil.org/assets/articles/indie-dev-stripe-payment/04-live-payment-e2e-verification-v1.svg)

正式环境上线收款的真机验收闭环：Agent 自动操作前序结账、手机真机扫码付款与 Webhook 日志核验

很多新手看到 Stripe 后台显示支付宝、微信支付已开启，或者网页能弹出收款二维码，就以为全部搞定了。但实际上， **后台开关亮了并不代表用户真能顺利完成付款和收到权益** （比如本地调试和线上生产环境的 Webhook 签名密钥 `whsec_` 是分开的，或者有时二维码能弹出来但实际扫码会报错）。

所以我的做法非常直接： **上线之后，我自己真实支付一次** 。只要我付完款能够正常收到授权码，或者能够正常购买并解锁产品，那我就认为它是成功了。线上真机测试我一般就直接付款测了，因为手续费其实不算很高，即便不退款，等着提现到自己卡上也行。

而且就算是做线上正式环境的测试，我们也不需要全靠手动一步步点：

我们可以直接让 AI Agent（配合浏览器工具）帮我们一路自动操作，跑到需要人为介入的步骤——也就是弹出二维码需要扫码支付的这个环节，我们自己拿手机扫一下完成支付；付完款之后，再让 AI Agent 继续去验证页面是否支付成功、权益是否到账，同时让 AI 去查看我们整个过程链路上的所有日志（包括 Stripe 回调记录和服务端日志），确认整条收款链路完全正常。
