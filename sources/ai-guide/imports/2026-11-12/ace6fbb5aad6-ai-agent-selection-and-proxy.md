很多刚接触 AI 编程或 Vibe Coding 的朋友，平时已经习惯了在网页版 ChatGPT、Claude 或 DeepSeek 的聊天框里问问题，准备进一步上手时往往会卡在最前面的三道门槛上：一是分不清大家常说的 AI Agent 工具和网页聊天框到底有什么区别；二是看着市面上五花八门的工具不知道第一款该装谁；三是好不容易装好了软件，又卡在海外套餐订阅和网络代理报错上。

这篇文章我们就把这几件事一次性理顺，帮你把趁手的工具和环境稳稳当当地搭起来。

## Agent 与网页聊天的区别

如果平时只用过网页版聊天框的朋友问我：「到底什么是 AI Agent？它跟我在网页里问 AI 有什么差别？」我会先跟他讲清楚两者在工作方式上的本质不同。

![网页版聊天工具一问一答返回文本与 AI Agent 自动规划并执行多步操作的对比](https://book.oiloil.org/assets/articles/ai-agent-selection-and-proxy/01-chat-vs-agent-v1.svg)

网页版聊天工具一问一答返回文本与 AI Agent 自动规划并执行多步操作的对比

网页版的聊天工具是 **一来一回** 的：你问它一个问题，它回答你一个问题，最终只能响应你一段文本。如果你想改代码或者做个网页，就得自己手动把代码复制进聊天框，等它生成新代码后，再由你复制粘贴回电脑本地的文件里去试。

而 **AI Agent 是会去执行实际行动的** 。当你向 AI Agent 提一个问题或交代一项任务时，它会先思考后面要怎么去执行行动，并且它手头有一系列可以直接调用的工具——比如说它可以去编辑你电脑本地的文件，可以去执行命令（比如帮你运行程序、安装依赖或启动网页预览），也可以去规划后续的任务。

更重要的一点是，AI Agent **可以基于自己执行命令的结果，再去规划下一步的操作** 。比如它改完文件后自己跑了一下命令，发现报错了，它不需要停下来等你复制报错信息，而是自己看到报错结果后接着思考下一步怎么修。所以在 AI Agent 最终回答你之前，它可能已经在背后自动执行过很多步操作了。

## 主流 AI Agent 怎么选

搞清楚了 AI Agent 是什么，接下来面对市面上众多的 Agent 工具，我们到底该怎么挑？

### 1\. 新手起步先用聚合型 Agent

其实新手最开始比较适合用一些 **聚合了多个模型的 Agent** ，比如说字节的 **Trae** 或者 **Cursor** 。因为在这类工具里可以直接切换不同厂商的模型，这样可以快速了解不同模型它们的一些特性——包括它们的 **交流感** 、它们的 **审美** ，以及它们 **写代码的能力差别** 和 **价格** 。

在这类聚合工具里， **我更加推荐 Cursor** ，因为它里面有各种顶尖模型，包括 **Claude** 、 **Gemini** 和 **GPT** ，拿来横向体验非常方便。

不过 **后续日常使用我就不推荐继续用 Cursor 了** ——因为 Cursor 调用外部模型的额度消耗很快，杠杆很低， **仅适合前期用来体验** 。

### 2\. 日常主力优先选第一方 Agent

等你体验过不同模型的差异、明确了自己日常主力想用哪几款模型之后，选择 Agent 工具时的核心取向就非常简单，就是看 **它能够让我用上什么模型** 。

为什么这么说？因为其实各家 AI Agent 里面的 Harness（也就是给模型配套的底层工具与执行框架）实现都是大差不差的；而且现在很多主流的 Agent 工具都是和特定模型绑定的。

比如我日常使用最多的就是 **Codex** 、 **Claude Code** 和 **Kimi Code** 。之所以主力使用这几个工具，原因就是我看中了它们背后的 **GPT** 、 **Claude** 和 **Kimi** 这三个模型——其中 Codex 和 OpenAI 的 GPT 模型绑定，Claude Code 和 Anthropic 的 Claude 模型绑定，Kimi Code 则和月之暗面的 Kimi 模型绑定。

为什么在确定主力模型后，我更推荐直接使用模型厂商自家的「第一方 Agent」？

核心原因在于： **第一方的 Agent 对于自己家模型的适配是最好的。**

现在的模型在后训练（也就是模型完成基础训练后，针对实际工具调用和任务执行做的专项训练）的时候，其实可以基于自己家的 Harness 去做针对性的提升；而且厂商自己家的 Harness 也是完全基于自家第一方的模型去开发和测试的。模型和工具框架是按照彼此的习惯一起打磨出来的，用起来自然最稳、最顺手。

![新手先用多模型聚合工具感受差异，摸清偏好后按主力模型选择原厂第一方桌面端](https://book.oiloil.org/assets/articles/ai-agent-selection-and-proxy/03-first-party-agent-and-desktop-ui-v1.svg)

### 3\. 门槛更低的国产第一方选择

如果你刚入门，觉得一上来就要搞定海外网络和海外支付门槛太高，市面上也有一些门槛更低的国产第一方 Agent 工具可以选，比如 **WorkBuddy** 、 **Z Code** 和 **MiniMax Code** 。它们同样和自家模型绑定——WorkBuddy 可以使用腾讯的 **混元** 模型，Z Code 可以使用智谱的 **GLM** 模型，MiniMax Code 则可以使用自家的 **MiniMax** 模型，并且它们都可以直接走国内自家的订阅，上手非常省心。

### 4\. 推荐直接使用桌面端应用

不少新手一听说 Codex、Claude Code 可以在命令行（黑框框）里跑，心里就容易犯怵。其实在客户端形态上， **我推荐大家直接使用桌面端的应用** 。

现在几乎所有这类主流的 Agent 产品都提供了桌面端应用，而且它们的界面布局几乎都是一致的： **左边是话题列表，右边是对话和命令输入的地方** 。你不需要去记复杂的命令行操作，像平时用聊天软件一样打开桌面端、选好文件夹就能直接开始干活。

## 主力模型的性格与强项

既然选 Agent 工具本质上是在选模型，那不同模型的「性格」有什么差别？刚上手时又该怎么挑？这里我给新手朋友两个很重要的建议：

![弱模型总是差一口气易劝退与强能力高交流感模型拆解需求稳落地的对比](https://book.oiloil.org/assets/articles/ai-agent-selection-and-proxy/04-strong-and-communicative-models-v1.svg)

弱模型总是差一口气易劝退与强能力高交流感模型拆解需求稳落地的对比

1. **优先使用能力比较强的模型，快速看清目前的上限** 。刚开始体验时，一定要先用目前能力比较强的模型。这能让我们快速了解到当前强模型的上限到底在哪里；如果你一开始为了追求性价比而选了一个弱模型，做出来的东西总是差一口气，很可能会直接打消你对 AI 探索的积极性。
2. **优先选择「交流感比较强」的模型** 。在我们刚上手、对 AI Agent 本身的工具和协作方式还没有那么了解的时候，强烈推荐选择交流感比较强的模型。交流感强的模型跟我们有更好的沟通感，能够很好地理解我们的真实意图，帮我们把一句话的需求拆解成具体任务，而不会稍微少交代一句就跑偏。

## 套餐订阅怎么配最划算

看完了模型和工具，下一步就是解决账号和费用问题。很多新手会纠结：我是应该去充值 API 按量计费，还是开按月付费的官方订阅套餐？套餐里好几个档位又该买哪一档？

### 1\. 为什么强烈推荐走订阅套餐？

**我非常推荐大家优先走各家的官方订阅套餐，因为订阅套餐有很高的杠杆。**

正常来说，AI 模型如果直接按 API 调用量去计费，价格是很高的——尤其是 AI Agent 在执行任务时，背后会连续跑很多步操作、反复读写文件，消耗的额度远比普通网页聊天大得多。而如果开通官方订阅套餐，我们往往可以得到 **所支付的订阅费用乘以几十倍的使用额度** ，划算非常多。

而在套餐档位的选择上， **我建议大家刚开始直接订阅最便宜的那一档（基础档，比如 ChatGPT Plus 这一档）即可** 。先用最便宜的一档套餐，在里面调用能力强、交流感好的模型把整个流程跑通，等以后真正高频重度使用了再考虑是否升档。

### 2\. 各家套餐的订阅方式与实操渠道

不同厂商的订阅门槛差异很大，这里按实际体验给大家梳理最省心的路径：

- **Claude（Claude Code）** ：目前 Claude 在国内是非常难订阅上的，而且账号风控极严，因此 **我不太推荐大家一上来就折腾 Claude** 。新手起步更建议先从下面的 **Codex** （海外首选）或 **Kimi Code / 国产第一方工具** （国内零门槛首选）开始。
- **Codex（ChatGPT 官方订阅）** ：默认情况下官方直接订阅需要海外的 MasterCard 等信用卡；如果大家想要买 Codex 的代充，可以在我自己提供的网站 [oil-gpt.com](https://oil-gpt.com/) 去充。
- **Gemini（Gemini Pro）** ：如果你想体验上面模型卡片里的 Gemini 系列模型，可以直接在 **闲鱼** 上面购买 Gemini Pro，价格非常便宜。
- **Kimi Code / WorkBuddy / Z Code / MiniMax Code** ：直接在各自官网用国内微信或支付宝开通官方订阅即可，没有任何海外支付门槛。

## 网络代理与 TUN 模式配置

如果你选择使用 Codex 等海外第一方 Agent 工具，最后一步就是把网络代理配好。

很多朋友经常遇到一个典型问题：明明电脑上开了代理、用浏览器也能正常打开海外网页，但一打开 Agent 客户端就一直转圈超时，或者提示地区不可用。我们可以按「 **选节点服务 → 装客户端导入订阅 → 开启 TUN 模式与美国节点** 」这三步，一次性把网络环境配稳。

### 1\. 代理节点网站与访问入口

新手朋友首先要分清两个概念： **代理网站负责提供节点线路，而下面会讲到的 Clash Verge Rev、FlClash 则是装在电脑上用来连接节点的客户端软件。** 只安装客户端软件本身是不能直接连上海外网络的，我们需要先在代理网站注册并获取「订阅链接」，再把订阅链接导入到客户端里使用。

下面整理了几个代理网站及其国内访问入口供大家参考：

- **FlyBit** ： [国内入口 1](https://www.fastfastfast.best/) · [国内入口 2](https://666.fastfastfast.buzz/) · [网址导航](https://goflybit.com/) · [GitHub 地址页](https://github.com/FlyBitVIP/FlyBit-Airport-Address)
- **WgetCloud** ： [国内备用入口](https://wgetcloud.ltd/) · [主官网](https://wgetcloud.org/)
- **Just My Socks** ： [国内镜像入口](https://justmysocks6.net/) · [主官网](https://justmysocks.net/)

挑选和使用时注意两点即可：

1. **确认包含美国区节点并支持 Clash 订阅** ：购买套餐时确认里面包含美国区（如 US / LA）节点，并在后台复制 **Clash（或 Mihomo / Clash.Meta）** 格式的订阅链接。
2. **建议先试用或从月付起步** ：不同地区和宽带运营商的网络环境会有差异，建议先试用或先按月开通最基础的一档，实测自己的网络环境下连接顺畅后再按需续费。

### 2\. 推荐的开源代理客户端与订阅导入

买好套餐后，代理客户端我推荐大家使用下面这两个开源仓库里的软件（点进 GitHub 页面右侧的 `Releases` 即可下载对应电脑系统的安装包）：

- **Clash Verge Rev** ： [github.com/clash-verge-rev/clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev)
- **FlClash** ： [github.com/chen08209/FlClash](https://github.com/chen08209/FlClash)

点进最新正式版页面后，展开底部的 **Assets** 下载安装包：Windows 电脑一般选名称带 `x64` 或 `amd64` 的 `setup.exe` ；Mac 电脑选 `.dmg` （苹果 M 系列芯片选 `arm64` / `aarch64` ，老款 Intel 芯片选 `x64` / `amd64` ）。

两款软件任选一款安装即可。装好后回到刚才购买的代理网站后台，找到「仪表盘」或「订阅中心」：

- 如果后台有「 **一键导入 Clash** 」按钮，直接点击并允许浏览器唤醒客户端即可自动完成配置；
- 如果没有一键按钮，就点击「 **复制 Clash / Mihomo 订阅链接** 」，打开客户端左边的「订阅」或「配置」页面，把链接粘贴进去下载并选中启用（注意：订阅链接相当于你的账号凭证，请勿发到公开群聊或来历不明的第三方转换网站）。
![安装开源代理客户端并导入 Clash 订阅配置](https://book.oiloil.org/assets/articles/ai-agent-selection-and-proxy/02a-proxy-client-import-v1.svg)

安装开源代理客户端并导入 Clash 订阅配置

### 3\. 两个必配的关键设置

装好代理客户端并导入节点配置之后，一定要检查以下两件事：

1. **必须开启 TUN 模式（虚拟网卡模式）** ：普通代理默认开启的「系统代理」往往只对浏览器生效，而 AI Agent 桌面端和它在底层调用的命令工具经常不会读取浏览器的系统代理。在 Clash Verge Rev 或 FlClash 设置里把 **TUN 模式** 打开（首次开启按提示授予系统权限），它会在系统层创建一个虚拟网卡，让电脑上所有 Agent 工具的流量都被客户端接管。
2. **使用 Codex 需要开启美国区的代理节点** ：Codex 对代理节点所在的地区有要求，建议在客户端的「代理 / 节点」页面里选中 **美国区** 的节点；如果你开启的是按网站分流的「规则模式」，并且节点列表里有单独的 **OpenAI / ChatGPT / AI** 分组，记得把该分组也一并切换为美国节点。
![在代理客户端中开启 TUN 虚拟网卡模式并切换美国区节点](https://book.oiloil.org/assets/articles/ai-agent-selection-and-proxy/02b-tun-mode-and-us-node-v1.svg)

在代理客户端中开启 TUN 虚拟网卡模式并切换美国区节点

把桌面端装好、最便宜一档的官方订阅开通、代理软件里的 TUN 模式和美国节点打开，再打开 Agent 试跑一次登录和对话，你的 AI Agent 环境就已经稳稳当当地准备就绪了。下一篇我们就正式打开桌面端，带你从 0 到 1 跑通第一次 AI Agent 实战操作。
