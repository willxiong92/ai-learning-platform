# AI 学习站

## 已确认的产品方向

依据：Will 在 2026-09-16 本次对话确认新建网站，由 Claude Code 的 Opus 5 推进，完成后由 Codex 审查。名称“AI学习站”为本轮可逆工作名。

这是团队维护、先供 Will 试学再逐步给团队使用的电子课本，面向非技术背景的 SaaS 客户成功、主管与交付人员。长期服务于“懂技术、能设计方案、能组织交付、能带团队复制”的职业方向。不是转成全职前端工程师的课程，也不是对客陪跑业务工作台。

教学顺序：课程地图与先修关系 → 教材讲解 → 示例与小练习 → 章节测验与纠错 → 本人试学修订 → 内容复核 → 团队试用。业务案例在概念讲明后承接应用，不能用连续追问代替授课。

原六门课程、24 个主题及每周 10 小时作为规划输入。允许重排先修顺序，不能把旧首四周客户陪跑任务直接当新站课程表。第一期建立完整目录，只精做第一章；其余章节明确“待编写”。

## 首期产品范围

| 入口 | 最小功能与验收 |
|---|---|
| 课程目录 | 展示目标、先修关系、章节状态、预计学习时间；时间为估计 |
| 章节教材 | 学习目标、术语解释、图例、正反例、示范、练习、来源与版本；能从零读懂 |
| 知识点查询 | 可搜索首期已有内容，链接回章节；无内容时显示真实空态 |
| 练习与测验 | 提交后解释正误和回看位置，支持重做；未答不能得分；简答与客观题分开 |
| 我的学习 | 阅读、练习、测验、待复习状态可区分；明确保存位置与限制 |

参考 https://vibe-hub.org/ 的知识组织、通俗解释和交互示例。需要实际浏览并记录所借鉴的页面，不照搬品牌、正文或未获许可代码。页面优先让学习者知道“从哪学、学什么、下一步是什么”，不继续叠加业务工具标签页。

## 内容与验收

教材正文在本项目 sources/ 维护一份可编辑母源；源码负责呈现，可生成构建内容但不手工维护第二套正文。具体内容格式由技术方案确定。课程须有来源、适用边界、版本和审阅状态。已有课本只能作为候选素材，需重新检查准确性和教学顺序。

学习成绩与教材验收分开：Will 看过答案后的重做不能当陌生题迁移能力；保留变式题用于后续验证。同事试用不虚构。不要仅凭一次选择题及格认定胜任岗位。及格线与关键题规则先作为可调整草案，由 Will 试学后确认。

阶段验收：技术可运行（Codex 检查）→ Will 能学懂并完成练习（本人验收）→ 团队可独立使用（实际试用）。三个结果分别记录。首期不预设提效比例或转岗结果。

## 明确不在本轮范围

- 不删除、改造或整仓复制旧主管工作坊；不迁移客户材料、行业配置、实时工具、FY27 业务规则。
- 不导入付费课程正文、客户原始数据、员工考核信息；首期用原创表达、可引用公开来源和合成例子。
- 不自动接通 AI API，不伪装真实模型调用；模拟演示必须标明。
- 不默认开发多用户账号、在线教材编辑后台、团队成绩管理或自动发布。若成为必要项，先说明成本与方案。
- 不复用旧站的 Sites 身份、远端、部署配置、密钥、数据库或 node_modules。
